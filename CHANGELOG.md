## 0.1.0

Initial release.

### Features

- Create an HTTPS listener with an `authenticate-oidc` default action, or attach
  authenticated rules to an existing listener.
- Resolve the authorization, token and user info endpoints from the identity
  provider `/.well-known/openid-configuration` document.
- Listener rules with every ALB condition and action type, per-rule OIDC
  overrides, and unauthenticated bypass rules.
- Compute the redirect URIs to whitelist at the identity provider.
